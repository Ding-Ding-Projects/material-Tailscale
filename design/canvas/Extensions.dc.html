Extensions can run · 擴充功能可以執行

Turn this off to stop every extension at once. Their permissions are kept.

An extension is a program that runs as you. The app hands it only what its permissions name, never keys, tokens, e-mail addresses or anything in the system vault, stops it after five seconds and checks every answer, but it cannot stop an extension from reading your files or using the network on its own. Add only extensions you trust.

🧩 Allow Web page?

Web page 1.0.0 stays off until you allow exactly what it asks for.

It asks to

  • devices
    peer-detailsSee one device's name, MagicDNS name, Tailscale addresses, operating system, online state, tags and exit-node role, when you run one of its actions on that device.
  • open_in_browser
    open-urlOpen a web link (http or https) in your browser as the result of an action.

It adds

  • open_in_browserOpen web page · An action in the menu of every device

It never receives

  • blockNode, machine, disco and auth keys
  • blockAdmin API access tokens
  • blockAccount e-mail addresses and login names
  • blockPublic network addresses of other devices
  • blockPasswords, authenticator secrets and anything in the system vault

An extension is a program that runs as you. The app decides what it hands over and which answers it accepts, but it cannot stop an extension from reading your files or using the network on its own. Allow only extensions you trust.

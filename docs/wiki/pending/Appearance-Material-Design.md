# Material 3 Expressive design

## Behaviour

Midnight Mesh 2 (designed on the design canvas, see [Design reference and parity](Appearance-Design-Reference)): page hero bands with animated illustrations for each page family, a two-pane Settings, in-page tabs with a sliding indicator, a setup state with steps, tonal icon tiles, zebra tables and live status dots, on top of Midnight Mesh: an ink-navy surface, periwinkle primary, mint secondary and amber tertiary derived from one seed colour in OKLCH, Outfit headings, Roboto Flex body and JetBrains Mono for commands. Expressive shapes morph on hover, buttons ripple, cards rise in with staggered motion and page changes use view transitions.

In-page tabs that run past an edge fade at that edge and show an arrow button, so a hidden section never looks like the end of the list; the arrows are for the mouse, and the arrow keys reach every tab. A segmented choice stretched across a card shares the width among its options, and a choice whose options no longer fit one row becomes a two-column grid instead of wrapping unevenly. Icons say what happens: automatic choices use an automatic icon and suggestions use a network-check icon, never decorative sparkles.

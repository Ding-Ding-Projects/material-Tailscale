# Command palette (Ctrl+Shift+F)

## Behaviour

Searches destinations, every CLI command and flag, every admin API operation, every setting (with its live value inline), every doc article and actions. Selecting a result teleports to the exact element with a highlight. Card or full-window size; plain text or regex.

The palette is a modal dialog: Tab and Shift+Tab stay inside it. The search box is a combobox driving the result list, so focus stays in the box while Up and Down move the active result. A setting's switch, choice, slider or colour is drawn inside its result: Left and Right change it in place, and Enter goes to the setting. The website's palette works the same way for the settings it offers.

## Configuration

Settings > Interface > Command palette size.

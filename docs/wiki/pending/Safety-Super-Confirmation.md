# Two-key super confirmation

## Behaviour

Destructive actions name the exact action and what is affected, then need two independently pressed keys before a full-range slider unlocks. Emergency exit and Escape always cancel.

## Configuration

Used for logout, resets, lock changes, device deletion, key revocation, policy file saves and bulk deletes.

## When something goes wrong

Releasing the slider early resets it.

## Security and privacy

Nothing runs until both keys and the full slide.

## How to verify

Try Reset Serve.

## 廣東話摘要

危險動作要兩條鎖匙加滑桿確認。

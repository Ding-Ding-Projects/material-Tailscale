# School mode

## Behaviour

One switch shared by every Ding-Ding-Projects app on this computer through a shared record in the application data folder. Turning it on forces English and hides funny levels, personal vocabulary and the dim sum surprise, live. It can be renamed and protected by a shared unlock password.

## Configuration

Settings > School mode.

## When something goes wrong

If the shared record cannot be read the mode stays off.

## Security and privacy

The password is stored as a SHA-256 hash.

## How to verify

Turn it on and check the language switch disappears.

## 廣東話摘要

所有程式共用嘅學校模式，可以改名同加密碼。

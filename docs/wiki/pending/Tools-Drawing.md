# Drawing board

## Behaviour

Seven pens (pen, marker, highlighter, pencil, brush, calligraphy, neon) and an eraser with shortcuts, Shift for straight strokes, undo and redo, guarded clear, SVG export and PNG at 1x to 3x, and annotation of a screenshot of the app.

## Configuration

Tools > Drawing board.

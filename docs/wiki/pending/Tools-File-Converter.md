# File converter

## Behaviour

Detects type from the first bytes, then converts structured data (JSON, CSV), images (PNG, JPEG, WebP) and binary encodings (Base64, hex). Documents, audio, video and archives are listed as disabled rows naming the tool they need, which is not bundled yet.

## Configuration

Tools > File converter.

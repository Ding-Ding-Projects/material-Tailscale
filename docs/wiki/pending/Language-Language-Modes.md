# Language modes

## Behaviour

English, playful Hong Kong Cantonese, or both. Bilingual keeps English prominent with Cantonese smaller beneath it. Commands, flags, IPs and API fields stay exact.

## Configuration

Settings > Language & voice > Language, the language switch on the website header, or the command palette.

## When something goes wrong

A missing translation falls back to English.

## Security and privacy

No network use.

## How to verify

Switch to Both and check the navigation rail and dialogs.

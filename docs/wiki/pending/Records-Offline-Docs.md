# Offline documentation

## Behaviour

Every article in this folder is bundled into the app at build time and rendered by one shared, sanitised Markdown renderer with regex search. The build fails if any article is missing from the bundle.

On wide windows (1280 pixels and up) an "On this page" list beside the article shows its section headings; choosing one scrolls to it, smoothly unless motion is reduced. The website's docs use the same reader.

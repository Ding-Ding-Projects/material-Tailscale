# Material 3 Expressive design

## Behaviour

Midnight Mesh 2 (designed on the design canvas, see [Design reference and parity](design-reference.md)): page hero bands with animated illustrations for each page family, a two-pane Settings, in-page tabs with a sliding indicator, a setup state with steps, tonal icon tiles, zebra tables and live status dots, on top of Midnight Mesh: an ink-navy surface, periwinkle primary, mint secondary and amber tertiary derived from one seed colour in OKLCH, Outfit headings, Roboto Flex body and JetBrains Mono for commands. Expressive shapes morph on hover, buttons ripple, cards rise in with staggered motion and page changes use view transitions.

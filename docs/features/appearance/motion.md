# Motion and reduced motion

## Behaviour

Every animation follows Material motion and has a reduced path: transitions become instant, looping animations stop, the rainbow settles on one hue. The operating system preference is always respected.

## Configuration

Settings > Accessibility > Motion, and schedules.

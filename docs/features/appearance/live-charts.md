# Live charts

## Behaviour

The Home traffic chart follows the Liveline style: eased line, pulsing live dot, gradient fill, animated range and value badge, scrub crosshair with tooltips, keyboard scrubbing with arrow keys, a screen-reader summary and honest waiting and stale states.

## Configuration

Refresh rate follows the status interval.

## When something goes wrong

No data shows "Waiting for live data".

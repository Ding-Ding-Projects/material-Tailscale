# Accessibility tools

## Behaviour

A title-bar menu with bigger and smaller text, high contrast, reduced motion, bold focus ring, larger targets, read this page aloud (passwords and commands excluded) and keyboard shortcuts. Hiding the button asks first; Settings and the palette still reach every tool.

Every control shows a focus ring when reached from the keyboard, including search boxes, steppers and sliders. Modal dialogs, the setup wizard and the command palette keep Tab inside them until they close. Scrolling boxes with nothing focusable inside become focusable so they scroll from the keyboard. The [every-surface sweep](every-surface-sweep.md) checks all of this on every surface before each release.

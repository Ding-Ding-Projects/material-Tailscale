# Window and navigation

## Behaviour

A frameless window with a custom title bar and working minimise, maximise and close, a navigation rail, and browser-style tabs: one workspace tab that ordinary navigation reuses, plus utility tabs opened only from New tab (Ctrl+T) or "Open in a new tab".

## Configuration

Tabs persist across restarts.

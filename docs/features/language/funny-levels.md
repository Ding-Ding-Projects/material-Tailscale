# Funny-level sliders and dialog emojis

## Behaviour

Two sliders, English and Cantonese, from 1 (fully serious) to 5 (most playful), both shipping at 5. They change the voice of every message category including errors, destructive, security and accessibility messages, never the facts. A separate switch adds one decorative emoji to dialogs and notifications.

## Configuration

Settings > Language & voice. Each slider resets independently.

## When something goes wrong

Levels 1 and 2 use the serious wording, 3 mild, 4 and 5 playful.

## Security and privacy

No network use.

## How to verify

Set English to 1 and trigger an error; set it to 5 and repeat.

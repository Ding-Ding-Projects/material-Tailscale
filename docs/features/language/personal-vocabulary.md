# Personal vocabulary JSON

## Behaviour

Upload or drop a personal vocabulary JSON to replace words in the interface. The file is validated in full: schemaVersion 1, an entries object of term to replacement, at most 256 KiB, depth 8, terms up to 160 characters, replacements up to 1,000, no duplicate keys or unsafe keys. A valid drop shows a full-window level-up celebration.

## Configuration

Settings > Personal vocabulary, or drop the file anywhere on the window.

## When something goes wrong

An invalid file is refused with the reason and nothing changes. Clearing restores original wording at once.

## Security and privacy

Parsing and storage are local. The file is never sent anywhere or exported.

## How to verify

Drop a valid file, see the celebration, then clear it.

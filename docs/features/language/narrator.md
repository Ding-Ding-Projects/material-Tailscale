# Narrator and voices

## Behaviour

Off by default. Speaks connection changes and command results in English, Cantonese or both, one utterance at a time with per-category cooldowns. Each language has its own voice picker listing installed voices with Choose automatically as the default; the voice actually in effect is stated beneath it, including a missing chosen voice. Rate and pitch are adjustable.

## Configuration

Settings > Narrator & sounds.

## When something goes wrong

If no voice exists for a language the picker says so.

## Security and privacy

Speech uses the operating system voices.

## How to verify

Turn it on, connect, and listen.

## 廣東話摘要

旁白：英文、廣東話或兩樣，每種語言自己揀聲音。

# Action sounds

## Behaviour

Short synthesised cues for connect, disconnect, success, errors and level-up. Quiet hours and Low stimulation silence them.

## Configuration

Settings > Narrator & sounds.

## When something goes wrong

Audio failures are ignored; every cue has a visual equivalent.

## Security and privacy

No files are played; sounds are generated.

## How to verify

Toggle sounds and run a command.

## 廣東話摘要

動作音效，可以關同設靜音時段。

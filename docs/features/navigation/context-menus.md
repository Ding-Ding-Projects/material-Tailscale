# Context menus

## Behaviour

Right-click works everywhere. Menus show working shortcuts, open with a filter field and a regex toggle, and include Edit appearance… and Lock this element…. Some carry live controls such as the theme.

## Configuration

Shift+F10 or the Menu key opens the menu for the focused element.

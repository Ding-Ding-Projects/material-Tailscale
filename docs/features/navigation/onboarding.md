# Setup wizard

## Behaviour

A first-run wizard that finds Tailscale, connects or signs in, sets language and funny levels, appearance and optionally the admin API, with progress, Back, Next, Skip, Finish later and resume.

## Configuration

Run it again from Settings > About.

## When something goes wrong

Each step reports real results, such as the paths searched.

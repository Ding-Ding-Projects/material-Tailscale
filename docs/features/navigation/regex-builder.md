# Regex builder

## Behaviour

Every search has a regex toggle and a builder: token palette, flags, live highlighting, groups, replacement preview, plain-language explanation, code for JavaScript, Python, Go, C# and PowerShell, escape as literal, a slow-pattern warning and a saved library. Full RegexBuddy parity is not claimed; see the roadmap.

## Configuration

Open from the wrench beside any search or Tools > Regex builder.

## When something goes wrong

Invalid patterns show the engine error inline.

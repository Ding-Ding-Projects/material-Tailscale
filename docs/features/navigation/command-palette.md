# Command palette (Ctrl+Shift+F)

## Behaviour

Searches destinations, every CLI command and flag, every admin API operation, every setting (with its live control inline), every doc article and actions. Selecting a result teleports to the exact element with a highlight. Card or full-window size; plain text or regex.

## Configuration

Settings > Interface > Command palette size.

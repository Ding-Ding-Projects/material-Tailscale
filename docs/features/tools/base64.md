# Base64 toolkit

## Behaviour

Standard, URL-safe and MIME variants, padding, strict or lenient decoding with error offsets, UTF-8, UTF-16LE and Latin-1, data: URLs, file encode with a verified SHA-256 round trip, type detection and image preview on decode.

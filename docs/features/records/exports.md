# Exports

## Behaviour

Lists, results, settings, history and the policy file export as JSON, YAML, CSV, Markdown, HTML or plain text, with any shape loss stated before export. Exports can open in VS Code or another detected editor.

## Configuration

The share icon on any result.

## When something goes wrong

Formats that cannot carry the data say so.
